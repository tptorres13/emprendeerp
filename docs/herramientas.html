Herramientas que usa el proyecto (explicado sin tecnicismos)

Lo que construye el sistema

HerramientaPara qué sirve
PythonEl idioma en el que está escrito el programa.
DjangoEl "esqueleto" del sistema: ya trae resueltas muchas cosas comunes (usuarios, páginas, seguridad), así no se arma todo de cero.
PostgreSQLLa base de datos: donde se guarda toda la información (productos, ventas, clientes). Es como un Excel gigante, ordenado y muy seguro.
HTML + Tailwind CSSLo que hace que las pantallas se vean lindas y se adapten al celular.
HTMXPermite que partes de la pantalla se actualicen sin recargar toda la página, para que se sienta rápido.
django-allauthSe encarga de registrarse, entrar, recuperar la contraseña y bloquear a quien intenta adivinar claves.
Argon2Guarda las contraseñas cifradas, para que nadie pueda leerlas, ni siquiera nosotros.
Gunicorn y WhitenoiseLos que "sirven" el sistema en internet cuando está publicado.

Lo que lo mantiene ordenado y seguro

HerramientaPara qué sirve
pytestCorre 47 pruebas automáticas que verifican que todo funcione, por ejemplo que un negocio nunca vea los datos de otro.
RuffRevisa que el código esté prolijo y sin errores comunes, como un corrector ortográfico.
pre-commitCorre esa revisión solo, antes de guardar cada cambio.
GitHub Actions (CI)Cada vez que se sube un cambio, repite todas las pruebas solo. Si algo se rompe, avisa.
uvAdministra las librerías que usa el proyecto y deja todo con versiones fijas, para que funcione igual en cualquier computadora.

Lo que lo hace fácil de instalar y publicar

HerramientaPara qué sirve
Docker y Docker ComposeEmpaquetan el sistema con todo lo que necesita. Con un solo comando se levanta igual en cualquier computadora o servidor.
MailpitUna "casilla de mail falsa" para ver los emails que manda el sistema (como el de recuperar contraseña) sin enviarlos de verdad.
Railway, Render o un VPSLos servicios donde se publicaría el sistema en internet. Todavía no elegimos ninguno.
GitHubDonde se guarda el código con todo su historial, y la copia de resguardo del proyecto.

Qué pasa cuando entrás al sistema

1. Te registrás con tu nombre, email y contraseña.

2. Un asistente de 3 pasos te pregunta el nombre del negocio, el rubro, la situación frente a ARCA y la moneda.

3. Te sugiere categorías según el rubro (por ejemplo, "Velas y aromas" para deco).

4. Entrás a tu inicio. Cada negocio ve solo sus propios datos.
